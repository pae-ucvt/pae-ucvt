# Методолог — AI-инструменты для педагогов

Набор инструментов на базе AI для автоматизации работы методиста и преподавателя: генерация программ повышения квалификации, планов занятий и тестов.

---

## Профиль

Создаю инструменты, которые упрощают рутинную работу в образовании:

- **Программы курсов** — ДПП повышения квалификации (36 ч, 72 ч) в формате .docx по стандарту
- **Планы занятий** — структурированные планы с хронометражем и описанием этапов
- **Тесты** — автоматическая генерация тестовых заданий с ключами

Цель — чтобы методист тратил время на содержание, а не на оформление.

---

## Проекты

### 1. Конструктор учебных программ

**Задача:** Быстро создавать программы повышения квалификации в формате .docx без ручного оформления.

**Что делает:**
- Принимает JSON-файл с данными программы (название, цель, занятия, темы)
- Генерирует готовый Word-документ с титулом, таблицами, разделами
- Поддерживает объёмы 36 часов (9 занятий) и 72 часа (18 занятий)

**Инструменты:**
| Файл | Назначение |
|------|------------|
| `scripts/build_program.py` | Параметрическая генерация .docx из JSON |
| `scripts/convert_to_docx.py` | Конвертация .md → .docx |
| `templates/constructor_template.md` | Шаблон с инструкцией по заполнению |

**Пример данных:** `Выпускной проект/Нейросети в работе преподавателя/neural_networks.json`

**Запуск:**

```bash
# 1. Установить зависимости
pip install python-docx openpyxl

# 2. Скопировать JSON-шаблон
cp "Выпускной проект/Нейросети в работе преподавателя/neural_networks.json" my_program.json

# 3. Заполнить данными (название, цель, занятия)

# 4. Сгенерировать .docx
python scripts/build_program.py my_program.json
```

**Результат:** `my_program.docx` — готовая программа с 7 разделами.

### 2. AI-ассистент методолога (субагент)

**Задача:** Генерировать учебные материалы по описанию на естественном языке.

**Что делает:**
- Программы курсов по теме и объёму
- Планы занятий с хронометражем
- Тесты с вопросами и ключами

**Команды:**

| Запрос | Результат |
|--------|-----------|
| `создай программу по теме "..." на 36 часов` | ДПП ПК из 7 разделов |
| `составь план занятия по теме "..."` | План с хронометражем |
| `сделай тест по теме "..."` | 10 вопросов + ключ |
