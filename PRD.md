# PRD: Конверсионный лендинг — курсы повышения квалификации по нейросетям

## 1. Продукт

Три программы повышения квалификации (32 ак.ч) от **Санкт-Петербургского Национального открытого Университета (НОУР)**:

| Код | Название | ЦА |
|-----|----------|-----|
| 4340 | Нейросети в профессии преподавателя | педагоги, методисты, тьюторы, воспитатели |
| 4341 | Нейросети в повседневной работе: анализ, автоматизация, оптимизация | офис-менеджеры, секретари, кадровики, бухгалтеры, аналитики |
| 4342 | Нейросети: основы творческой работы для решения креативных задач | маркетологи, SMM, дизайнеры, продюсеры |

**Формат:** очно (СПб) или онлайн (вебинар в реальном времени, не запись)
**Документ:** удостоверение о повышении квалификации, вносится в ФИС ФРДО
**Лицензия:** №2141 от 06.09.16, Комитет по образованию СПб
**Цена:** уточняется (на странице-источнике подгружается через JS)

## 2. УТП (главные сообщения)

**Основной крючок:** «Государственное удостоверение с занесением в ФРДО — официально подтвердите владение нейросетями для аттестации и карьеры»

**Дифференциатор:** «Не запись — живой вебинар с преподавателем, практика 32 часа, своё портфолио промптов»

## 3. Целевая аудитория (сегменты)

**Сегмент А — Педагоги (основной):**
- Учителя школ, преподаватели колледжей и вузов
- Воспитатели, логопеды ДОУ
- Методисты
- Боль: нужно удостоверение для аттестации, нейросети требуют Минпросвещения / регионы

**Сегмент Б — Офисные сотрудники:**
- Бухгалтеры, кадровики, делопроизводители
- Помощники руководителей, офис-менеджеры
- Аналитики
- Боль: рутина с документами отнимает 60% времени, нейросети автоматизируют

**Сегмент В — Креативные специалисты:**
- Маркетологи, SMM-менеджеры
- Дизайнеры, продюсеры онлайн-курсов
- PR-менеджеры
- Боль: нужно выдавать контент быстро и качественно

## 4. Структура лендинга

### Hero-секция (первый экран)

**Макет:**
- Фон: тёмно-синий / фиолетовый градиент с абстрактными нейросетевыми паттернами
- Логотип НОУР в углу
- Контакты (телефон, email)

**Вариант заголовка A (короткий, сильный):**
> **«Официальное удостоверение ФРДО по нейросетям. Очно или в прямом эфире — без записей и устаревших программ»**

**Вариант заголовка B (про боль):**
> **«Надоели курсы-записи, где всё устарело через месяц? Получите живое обучение и госудостоверение ФРДО»**

**Вариант заголовка C (про карьеру):**
> **«Повышение квалификации по нейросетям: очные занятия или вебинары в реальном времени + удостоверение ФРДО для аттестации»**

**Подзаголовок:**
> «32 часа очных аудиторных занятий в Санкт-Петербурге или живых вебинаров с преподавателем. Не запись — прямая речь, ответы на вопросы, актуальные версии инструментов. Лицензия №2141»

**Кнопки:** три кнопки — «Для преподавателей» / «Для офиса» / «Для креативных»

### Секция «Польза» (блок 1 — Почему это важно)

3-4 карточки преимуществ:

1. **Государственное удостоверение** — данные вносятся в ФИС ФРДО, подходит для аттестации и отчётов
2. **Живой эфир, а не запись** — вебинар с преподавателем, можно задать вопрос, получить обратную связь
3. **32 часа практики** — не теория, а своё портфолио промптов под ваши задачи
4. **Налоговый вычет** — для физических лиц возврат 13% стоимости обучения

### Секция «Три программы — выберите свою» (блок 2 — Детализация)

Три колонки с карточками программ:

**Программа 1 — Для преподавателей**
- Для кого: преподаватели СПО, вузов, педагоги дополнительного образования, методисты, тьюторы, воспитатели ДОУ
- Чему научитесь: готовить конспекты и презентации за минуты, создавать задания и тесты через нейросети, адаптировать контент под уровень и возраст аудитории
- Результат: мини-портфолио промптов для педагога
- Кнопка: «Записаться»

**Программа 2 — Для офиса**
- Для кого: менеджеры, секретари, кадровики, бухгалтеры
- Чему научитесь: автоматизировать отчёты, письма и документы, анализировать данные через ИИ, экономить 20–40% времени на рутине
- Результат: шаблоны промптов для офисных задач
- Кнопка: «Записаться»

**Программа 3 — Для креативных**
- Для кого: маркетологи, SMM, дизайнеры, продюсеры
- Чему научитесь: генерировать текст, изображения, видео для контента, создавать айдентику и презентации, продвинутый промптинг
- Результат: готовый проект (учебный модуль / контент-кампания / офисный продукт)
- Кнопка: «Записаться»

### Секция «Доверие» (кейсы, факты, отзывы)

- **Лицензия** — номер 2141 от 06.09.16, Комитет по образованию СПб (скриншот / иконка)
- **ФРДО** — удостоверение вносится в Федеральный реестр (иконка)
- **Опыт** — университет работает с 2016 года
- **Отзывы** — блок отзывов реальных слушателей (карусель или 2-3 отзыва)
- **Партнёры** — логотипы ВУЗов-партнёров, постоянных клиентов
- **Соц.доказательство** — «Вступи в группу VK / Telegram — получи скидку 5%»

### Секция CTA — Форма заявки

Форма на 4 поля:
- Имя
- Телефон
- Email
- Выбор программы (выпадающий список: преподавательская / офисная / креативная / не знаю — помогите выбрать)
- Кнопка: «Получить консультацию» или «Записаться»

Дополнительно: чекбокс «Согласие на обработку данных»

- Ссылки: VK, Telegram

- Политика конфиденциальности
- Копирайт

## 5. Технические требования

**Стек:** HTML + CSS + JavaScript (чистый, без фреймворков, или на выбор исполнителя)
**Адаптивность:** десктоп + планшет + мобильные
**Формы:** отправка заявки без перезагрузки (AJAX)
**Хостинг:** не нужен, разрабатываем локально
**Аналитика:** не нужна на этом этапе (можно добавить позже)
**Совместимость:** Chrome, Firefox, Safari, Edge (последние 2 версии)

## 6. Дизайн-референсы

**Тон:** доверительно-тёплый
**Цвета:** тёмно-синий (университетский), белый, акцентный голубой/бирюзовый
**Шрифты:** современные, читаемые (Montserrat / Roboto / аналоги системные)
**Графика:** абстрактные нейросетевые визуалы, иконки, минимализм

## 7. Требования к наполнению

- Весь текст написан простым языком, без канцелярита
- Акцент на выгоду для слушателя (а не на функции)
- Каждое преимущество подкреплено фактом
- Формы короткие, не пугающие

## 8. Критерии готовности

- Вёрстка всех секций (Hero, Польза, Программы, Доверие, CTA, Футер)
- Форма отправляет данные (на тестовый endpoint или в консоль на этапе разработки)
- Адаптив под мобильные и планшеты
- Все ссылки и кнопки работают
