### Тема 1.1. Что такое искусственный интеллект: понятия, виды, ключевые технологии (нейронные сети, машинное обучение, большие языковые модели)

**Форма занятия:** лекция с элементами практикума (1,5 ч: 1 ч лекция + 0,5 ч практика)

**Учебные вопросы:**
1. Определение ИИ, его место среди сквозных технологий цифровой экономики.
2. Классификация видов ИИ: слабый (узкий), общий, сильный — различия, текущее состояние развития.
3. Ключевые технологии: машинное обучение (обучение с учителем, без учителя, с подкреплением), нейронные сети, глубокое обучение.
4. Большие языковые модели (LLM): архитектура «трансформер», принцип предсказания следующего токена, области применения и ограничения.
5. Связь понятий: данные → модель → обучение → предсказание / генерация.

**Практическое задание:**
Слушатели в парах формулируют своё понимание термина «искусственный интеллект» (3–5 предложений), затем сравнивают с определением из Национальной стратегии развития ИИ. Заполняют шаблон: «Я думал, что ИИ — это … / На самом деле ИИ — это … / Ключевое различие в том, что …». Краткое обсуждение в группе: какие представления изменились.

**Самостоятельная работа:** —

**Ключевые понятия:** искусственный интеллект, машинное обучение, нейронная сеть, глубокое обучение, большая языковая модель (LLM), трансформер, обучение с учителем / без учителя / с подкреплением, данные, модель, токен.

### Тема 1.2. Обзор современных ИИ-инструментов: текстовые, визуальные, аудио, видео

**Форма занятия:** практикум (1,5 ч: 0,5 ч обзор + 1 ч практика с AI-аудитом)

**Учебные вопросы:**
1. Классификация ИИ-инструментов по типу контента: текст (ChatGPT, YandexGPT, GigaChat), изображения (Kandinsky, Шедеврум, Midjourney), аудио (SpeechKit, Whisper, нейромузыка), видео (генерация и обработка).
2. Российские и зарубежные решения: доступность, язык, функционал, ограничения для образования.
3. Базовые сценарии использования каждого типа инструментов в работе учителя-предметника.
4. Критерии выбора ИИ-инструмента под конкретную педагогическую задачу.

**Практическое задание (AI-аудит текущего инструментария):**
Слушатель составляет перечень ИИ-инструментов по четырём категориям: знаю / использую эпизодически / использую регулярно / не знаю, но предполагаю, что они существуют. Затем выполняет AI-аудит своего перечня:

**Промпт для AI-аудита:**
«Ты — эксперт по ИИ-инструментам для образования. Проведи аудит моего текущего знания ИИ-инструментов по категориям: текстовые, визуальные, аудио, видео. Вот мой список: [вставить]. Для каждой категории найди: 1) какие инструменты у меня отсутствуют, 2) какие из перечисленных устарели или малоэффективны, 3) какие инструменты я, скорее всего, не знаю, но они важны для учителя. Не предлагай готовый список — сначала диагностируй пробелы. Ответ дай в таблице: Категория / Мои инструменты / Пробелы / Почему это важно / Рекомендация.»

Результаты обсуждаются в группе: составляется общая карта инструментария, выявляются самые частые пробелы.

**Самостоятельная работа:** —

**Ключевые понятия:** текстовый генератор, визуальный генератор, синтез речи, распознавание речи, нейромузыка, генерация видео, промпт, российские ИИ-решения.

### Тема 1.3. Национальная стратегия развития ИИ до 2030 года и федеральный проект «ИИ» — контекст для школы

**Форма занятия:** лекция (1 ч)

**Учебные вопросы:**
1. Национальная стратегия развития ИИ до 2030 года (Указ Президента РФ № 490 от 10.10.2019): цели, задачи, целевые показатели.
2. Федеральный проект «Искусственный интеллект»: ключевые мероприятия, сроки, исполнители.
3. Связь государственной политики в области ИИ с ФГОС и требованиями к результатам обучения.
4. Роль школы в подготовке кадров для ИИ-экономики: профориентация, цифровая грамотность, компетенции XXI века.
5. Ключевые инициативы и программы развития ИИ-образования в России.

**Самостоятельная работа (0,5 ч):**
Изучить текст Национальной стратегии развития ИИ (актуальная редакция). Выписать 3–5 положений, непосредственно касающихся общего образования. Подготовить устный комментарий (1–2 мин) на тему: «Как Национальная стратегия влияет на мою работу как учителя».

**Ключевые понятия:** Национальная стратегия развития ИИ, федеральный проект «Искусственный интеллект», цифровая экономика, кадры для ИИ, сквозные технологии, целевые показатели.

### Тема 1.4. AI-аудит: что это и зачем учителю. Модель 5П (Понятность, Полнота, Противоречия, Проблемы, Предложения)

**Форма занятия:** практикум (2 ч: 1,5 ч аудиторная работа + 0,5 ч самостоятельная работа)

**Учебные вопросы:**
1. Понятие AI-аудита: перевод ИИ из режима исполнителя в режим проверяющего. Чем аудит отличается от генерации.
2. Модель 5П: Понятность (что неясно), Полнота (чего не хватает), Противоречия (где ломается логика), Проблемы (что может пойти не так), Предложения (как исправить).
3. Универсальная структура промпта для аудита: роль, материал, критерии, формат, ограничение.
4. Проверка с разных ролей (ученик, учитель, родитель) как способ повысить качество диагностики.
5. Ограничения AI-аудита: галлюцинации, смешение фактов и предположений, безопасность персональных данных.

**Практическое задание (AI-аудит с моделью 5П, проверка с разных ролей):**
Слушатель формулирует своё объяснение темы «Что такое искусственный интеллект» (5–7 предложений) — так, как объяснил бы это ученику. Затем выполняет AI-аудит:

**Промпт для AI-аудита (модель 5П + совет ролей):**
«Ты — методист по AI-грамотности. Проверь моё объяснение темы "Что такое искусственный интеллект" с позиции трёх ролей: (1) ученик 7 класса, (2) учитель-предметник без технического бэкграунда, (3) родитель, скептически настроенный к ИИ. Для каждой роли примени модель 5П:
- **Понятность:** что в моём объяснении будет неясно этой роли?
- **Полнота:** чего не хватает для верного представления?
- **Противоречия:** есть ли логические разрывы или нестыковки?
- **Проблемы:** какие риски или возражения возникнут?
- **Предложения:** что конкретно изменить?

Вот моё объяснение: [вставить]. Ответ дай в таблице: Роль / Понятность / Полнота / Противоречия / Проблемы / Предложения. В конце выдели 3 главные правки, которые улучшат объяснение для всех ролей сразу.»

После получения результатов слушатель:
1. Анализирует общие и специфические проблемы для каждой роли.
2. Исправляет своё объяснение с учётом рекомендаций.
3. Обсуждает в группе: как AI-аудит изменил его подход к объяснению материала.

**Самостоятельная работа (0,5 ч):**
Применить модель 5П к одному из своих реальных учебных материалов (фрагмент урока, памятка для учеников, текст для родительского собрания). Выполнить AI-аудит с позиции двух ролей (ученик + родитель или ученик + методист). Зафиксировать, что изменилось после аудита, какие правки внесены.

**Ключевые понятия:** AI-аудит, модель 5П (Понятность, Полнота, Противоречия, Проблемы, Предложения), роль проверяющего, диагностика vs улучшение, совет ролей, факты vs выводы vs предположения, галлюцинации ИИ, безопасность данных.
