# 4. Итоговая практическая работа (для защиты)

## Описание задания

**Цель:** разработать фрагмент урока / внеурочного занятия (15–20 минут) с использованием ИИ, провести полный AI-аудит разработанного фрагмента по 5 шагам, внести доработки и оформить отчёт для защиты.

**Формат сдачи:** письменный отчёт + устная защита (5–7 минут).

### Этапы выполнения работы

#### Этап 1. Разработка фрагмента урока

Выберите предмет, класс и тему. Разработайте фрагмент урока (15–20 минут), на котором ученики используют ИИ как инструмент для решения учебной задачи (не как «ответчика»).

Заполните таблицу-конструктор:

| Элемент | Содержание |
|---|---|
| Предмет, класс, тема | |
| Цель фрагмента (измеримая, с ИИ-компонентом) | |
| ИИ-инструмент (с обоснованием выбора) | |
| Этапы фрагмента с указанием времени | |
| Задание для учеников (инструкция, промпт) | |
| Критерии оценивания | |
| Ожидаемый продукт | |

#### Этап 2. Полный AI-аудит (5 шагов)

Проведите последовательный AI-аудит разработанного фрагмента с помощью промптов. Для каждого шага зафиксируйте результаты в таблице.

**Шаг 1. Аудит цели и задач (по модели 5П)**

Промпт:
```
Ты — методист с опытом педагогического дизайна. Проведи аудит формулировки цели и задач фрагмента урока по модели 5П. Вот данные:

Предмет: [предмет]
Класс: [класс]
Тема: [тема]
Цель фрагмента: [цель]
Задачи: [задачи]

Проверь по 5 критериям:
1. Понятность — что неясно, размыто, допускает двойное толкование
2. Полнота — чего не хватает (возраст, инструмент, результат)
3. Противоречия — где логика ломается
4. Проблемы — что может пойти не так
5. Предложения — как исправить каждую найденную проблему

Не переписывай цель и задачи сразу. Сначала найди слабые места. Ответ дай в таблице: критерий / найденная проблема / почему это риск / предложение по исправлению.
```

**Шаг 2. Аудит структуры урока (логика, полнота, противоречия)**

Промпт:
```
Ты — эксперт по проектированию уроков. Проведи аудит структуры фрагмента урока.

Вот структура:
— Класс: [класс]
— Тема: [тема]
— Этапы фрагмента: [перечислить этапы с указанием времени]
— Деятельность учителя: [описание]
— Деятельность учеников: [описание]
— Использование ИИ: [как и на каком этапе]

Проверь:
1. Логику последовательности этапов (есть ли разрывы, скачки)
2. Полноту (есть ли вход в тему, инструктаж, работа с ИИ, рефлексия)
3. Временные пропорции (реально ли уложиться)
4. Соответствие деятельности учеников заявленной цели
5. Наличие инструкции по работе с ИИ для учеников

Ответ дай в таблице: зона проверки / что нашёл / риск / рекомендация.
```

**Шаг 3. Проверка с 5 ролей (Совет экспертов)**

Промпт:
```
Ты — AI-ассистент. Проверь этот фрагмент урока с позиции пяти ролей. Для каждой роли найди 3 главных замечания и предложи, что изменить.

Материал для проверки:
[вставить описание фрагмента урока]

5 ролей:
1. Ученик («Клиент») — что непонятно, скучно, невыполнимо? Что его может демотивировать?
2. Завуч («Руководитель») — соответствует ли ФГОС? Есть ли измеримый результат? Реалистично ли по времени и ресурсам?
3. Слабый ученик («Новичок») — какие шаги пропущены? Где ему потребуется дополнительная помощь? Что он сделает не так?
4. Методист («Скептик») — почему это может не сработать? Где нарушена методика? Какие риски не учтены?
5. Коллега («Редактор») — что можно улучшить в формулировках, инструкциях, критериях? Где вода или лишнее?

Не переписывай материал полностью. В конце выдели 5 правок, которые дадут наибольший эффект.
```

**Шаг 4. Проверка на безопасность (факты vs выводы vs предположения)**

Промпт:
```
Проверь свой ответ по аудиту урока. Раздели его на три блока:
1. Факты — что основано на исходных данных учителя (предмет, класс, цель, этапы)
2. Выводы — что логически следует из фактов
3. Предположения — что нужно дополнительно проверить (мотивация учеников, доступность ИИ, реальное время)

Для каждого предположения напиши, какие данные нужны для подтверждения. Если где-то ты мог ошибиться или додумать, укажи это явно.
```

**Шаг 5. Финальные рекомендации**

Промпт:
```
Ты — методист. На основе всех проведённых аудитов составь финальные рекомендации по доработке фрагмента урока. Сгруппируй рекомендации по приоритету:
1. Критические — без исправления урок проводить нельзя
2. Важные — существенно улучшат качество урока
3. Желательные — сделают урок сильнее, но некритично

Для каждой рекомендации укажи: что именно изменить, как это повлияет на урок и на какой этап проектирования (цель / формат / инструмент / задание / критерии) она влияет.
```

1. Определите, какие правки являются критическими, какие — важными, какие — желательными
2. Внесите изменения в исходный фрагмент урока
3. Проведите повторный (сокращённый) аудит одной из ролей для проверки исправлений

Промпт для повторного аудита:
```
Ты — тот же методист, который проводил аудит ранее. Учитель внёс правки по твоим рекомендациям. Проверь обновлённую версию фрагмента урока. Оцени: какие проблемы решены, какие остались, не появились ли новые. Ответ дай в таблице: статус проблемы (решена / частично решена / не решена) / комментарий.
```
