# Модуль 5. «Проектирование и AI-аудит учебного занятия с ИИ» (6 часов)

**Распределение часов:** лекция — 1, практика — 4, самостоятельная работа — 1

---

## 5.1. Алгоритм проектирования урока с ИИ: цель → формат → инструмент → задание → критерии (лекция — 1 ч)

### Учебные вопросы
1. Логика проектирования: почему порядок «цель → формат → инструмент → задание → критерии» — критичен.
2. Постановка цели урока / фрагмента: предметный результат + формирование ИИ-грамотности.
3. Выбор формата: урок, внеурочное занятие, практикум, проектная сессия.
4. Выбор ИИ-инструмента под цель и возраст: текстовые (GigaChat, YandexGPT), визуальные (Шедеврум), анализ данных.
5. Проектирование задания для учеников: инструкция с ИИ, ожидаемый продукт, время.
6. Критерии оценивания результата (для учителя и для ученика).
7. AI-аудит как завершающий этап проектирования: проверить, что спроектированное работает до того, как идти в класс.

### Форма занятия
Лекция-визуализация с разбором примера: сквозной кейс «Фрагмент урока биологии в 7 классе: классификация растений с ИИ». На каждом этапе (цель → формат → инструмент → задание → критерии) показывается, как меняется проект.

### Ключевые понятия
Проектирование урока, цель занятия, ИИ-инструмент, учебное задание, критерии оценивания, AI-аудит, цикл проектирования.

## 5.2. Разработка собственного фрагмента урока / внеурочного занятия с ИИ (практика — 2 ч)

### Учебные вопросы
1. Выбор темы и предмета для фрагмента урока.
2. Постановка цели по алгоритму: «Ученик научится… с помощью ИИ».
3. Подбор ИИ-инструмента под возраст и задачу.
4. Формулировка задания для учеников (инструкция, промпты, ожидаемый продукт).
5. Подготовка критериев оценивания.

### Форма занятия
Групповая работа в предметных треках (естественно-научный, гуманитарный, информационно-технологический). Каждая группа разрабатывает один фрагмент урока (15–20 минут) по следующей структуре:

| Элемент | Пример заполнения |
|---|---|
| Предмет, класс, тема | |
| Цель фрагмента | |
| ИИ-инструмент | |
| Задание для учеников (с промптом) | |
| Критерии оценивания | |
| Ожидаемый продукт | |

### Практическое задание
Разработайте фрагмент урока / внеурочного занятия по своему предмету, где ученики используют ИИ как инструмент, а не как «ответчик». Заполните таблицу-конструктор.

**Пример промпта для генерации вариантов задания (для учителя):**

> Ты — методист-предметник. Помоги учителю сформулировать задание для фрагмента урока. Предмет: [предмет]. Класс: [класс]. Тема: [тема]. Цель: ученики должны применить ИИ для решения учебной задачи, а не просто получить ответ. Предложи 3 варианта задания с разной степенью самостоятельности учеников. Для каждого укажи: формулировку задания, какой ИИ-инструмент используется, какой промпт дать ученикам, ожидаемый продукт.

**Пример промпта для подбора ИИ-инструмента:**

> Ты — эксперт по образовательным ИИ-инструментам. Учитель хочет провести фрагмент урока по теме [тема] в [класс] классе. Цель фрагмента: [цель]. Предложи 2–3 подходящих ИИ-инструмента (свободных или доступных в России) для выполнения этого задания. Для каждого укажи: как именно инструмент используется, какие риски есть, какой уровень подготовки учеников нужен.

### Ключевые понятия
Фрагмент урока, учебное задание с ИИ, предметный трек, промпт для ученика, конструктор урока.

## 5.3. AI-аудит разработанного урока: проверка логики, полноты, рисков (практика — 1,5 ч)

### Учебные вопросы
1. AI-аудит как кульминация проектирования: от генерации — к проверке.
2. Полный цикл AI-аудита урока: от цели до финальных рекомендаций.
3. Проверка формулировки цели и задач по модели 5П.
4. Аудит структуры урока: логика, полнота, противоречия.
5. Проверка с 5 ролей: клиент (ученик), руководитель (завуч), новичок (слабый ученик), скептик (методист), редактор (коллега).
6. Проверка на безопасность: разделение фактов, выводов и предположений.
7. Формирование финальных рекомендаций.

### Форма занятия
Практикум: каждая группа прогоняет свой разработанный фрагмент урока через последовательность промптов AI-аудита. Результаты фиксируются в таблице аудита.

### Практическое задание (пошаговый AI-аудит)

**Шаг 1. Аудит формулировки цели и задач (по 5П)**

Промпт:

> Ты — методист с опытом педагогического дизайна. Проведи аудит формулировки цели и задач фрагмента урока по модели 5П. Вот данные:
>
> Предмет: [предмет]
> Класс: [класс]
> Тема: [тема]
> Цель фрагмента: [цель]
> Задачи: [задачи]
>
> Проверь по 5 критериям:
> 1. **Понятность** — что неясно, размыто, допускает двойное толкование
> 2. **Полнота** — чего не хватает (возраст, инструмент, результат)
> 3. **Противоречия** — где логика ломается (цель не соответствует задачам, задача не соответствует возрасту)
> 4. **Проблемы** — что может пойти не так (ученики не поймут, ИИ недоступен, время не хватит)
> 5. **Предложения** — как исправить каждую найденную проблему
>
> Не переписывай цель и задачи сразу. Сначала найди слабые места. Ответ дай в таблице: критерий / найденная проблема / почему это риск / предложение по исправлению.

**Шаг 2. Аудит структуры урока (логика, полнота, противоречия)**

Промпт:

> Ты — эксперт по проектированию уроков. Проведи аудит структуры фрагмента урока.
>
> Вот структура:
> — Класс: [класс]
> — Тема: [тема]
> — Этапы фрагмента: [перечислить этапы с указанием времени]
> — Деятельность учителя: [описание]
> — Деятельность учеников: [описание]
> — Использование ИИ: [как и на каком этапе]
>
> Проверь:
> 1. Логику последовательности этапов (есть ли разрывы, скачки)
> 2. Полноту (есть ли вход в тему, инструктаж, работа с ИИ, рефлексия)
> 3. Временные пропорции (реально ли уложиться)
> 4. Соответствие деятельности учеников заявленной цели
> 5. Наличие инструкции по работе с ИИ для учеников
>
> Ответ дай в таблице: зона проверки / что нашёл / риск / рекомендация.

**Шаг 3. Проверка с 5 ролей**

Промпт:

> Ты — AI-ассистент. Проверь этот фрагмент урока с позиции пяти ролей. Для каждой роли найди 3 главных замечания и предложи, что изменить.
>
> Материал для проверки:
> [вставить описание фрагмента урока]
>
> **5 ролей:**
> 1. **Ученик («Клиент»)** — что непонятно, скучно, невыполнимо? Что его может демотивировать?
> 2. **Завуч («Руководитель»)** — соответствует ли ФГОС? Есть ли измеримый результат? Реалистично ли по времени и ресурсам?
> 3. **Слабый ученик («Новичок»)** — какие шаги пропущены? Где ему потребуется дополнительная помощь? Что он сделает не так?
> 4. **Методист («Скептик»)** — почему это может не сработать? Где нарушена методика? Какие риски не учтены?
> 5. **Коллега («Редактор»)** — что можно улучшить в формулировках, инструкциях, критериях? Где вода или лишнее?
>
> Не переписывай материал полностью. В конце выдели 5 правок, которые дадут наибольший эффект.

**Шаг 4. Проверка на безопасность (факты vs выводы vs предположения)**

Промпт:

> Проверь свой ответ по аудиту урока. Раздели его на три блока:
> 1. **Факты** — что основано на исходных данных учителя (предмет, класс, цель, этапы)
> 2. **Выводы** — что логически следует из фактов
> 3. **Предположения** — что нужно дополнительно проверить (мотивация учеников, доступность ИИ, реальное время)
>
> Для каждого предположения напиши, какие данные нужны для подтверждения. Если где-то ты мог ошибиться или додумать, укажи это явно.

**Шаг 5. Финальные рекомендации**

Промпт:

> Ты — методист. На основе всех проведённых аудитов составь финальные рекомендации по доработке фрагмента урока. Сгруппируй рекомендации по приоритету:
> 1. **Критические** — без исправления урок проводить нельзя
> 2. **Важные** — существенно улучшат качество урока
> 3. **Желательные** — сделают урок сильнее, но некритично
>
> Для каждой рекомендации укажи: что именно изменить, как это повлияет на урок и на какой этап проектирования (цель / формат / инструмент / задание / критерии) она влияет.

### Таблица аудита (для заполнения группами)

| Шаг аудита | Что проверяли | Найденные проблемы | Рекомендации |
|---|---|---|---|
| 1. Цель и задачи (5П) | | | |
| 2. Структура урока | | | |
| 3. Проверка с 5 ролей | | | |
| 4. Безопасность | | | |
| 5. Финальные рекомендации | | | |

### Ключевые понятия
AI-аудит, модель 5П, многоролевая проверка, факты vs выводы vs предположения, безопасность ИИ, педагогический дизайн.

## 5.4. Доработка урока по результатам аудита (практика — 0,5 ч)

### Учебные вопросы
1. Анализ результатов аудита: что править в первую очередь.
2. Внесение изменений в цель, структуру, задание, критерии.
3. Повторный аудит: проверка, что правки сработали.

### Форма занятия
Групповая работа: каждая группа дорабатывает свой фрагмент урока по результатам таблицы аудита. Затем проводит повторный (сокращённый) аудит одной из ролей для проверки исправлений.

### Практическое задание

**Повторный аудит после правок (сокращённый):**

> Ты — тот же методист, который проводил аудит ранее. Учитель внёс правки по твоим рекомендациям. Проверь обновлённую версию фрагмента урока. Оцени: какие проблемы решены, какие остались, не появились ли новые. Ответ дай в таблице: статус проблемы (решена / частично решена / не решена) / комментарий.

### Ключевые понятия
Доработка, повторный аудит, итерация, приоритизация правок.

## Модуль 6. Итоговая аттестация (2 часа)

**Форма проведения:** итоговое тестирование (1 ч) + защита практической работы (1 ч).

---

### 6.1. Итоговое тестирование (1 ч)

Тест состоит из 20 вопросов. Приведены 5 примеров.

#### Примеры вопросов

**Вопрос 1.** Учитель хочет, чтобы ученики 7 класса использовали ИИ для создания ментальной карты по теме «Природные зоны России». Какой инструмент наиболее подходит?

- A) Текстовый генератор (GigaChat) — ученики просят написать текст, а затем делают карту
- B) Инструмент для визуализации (YandexGPT с плагинами или аналоги) — ученики создают схему на основе промпта
- C) Калькулятор — для расчёта площади природных зон
- D) Поисковик — ученики ищут готовые карты

**Правильный ответ: B** (инструмент должен соответствовать типу результата — ментальная карта как визуальная схема).

---

**Вопрос 2.** Учитель написал цель урока: «Познакомить учеников с возможностями ИИ». Какая проблема в этой формулировке?

- A) Слишком длинная формулировка
- B) Нет указания на инструмент
- C) Цель не измерима — непонятно, как проверить, что «познакомил»
- D) Цель не соответствует ФГОС

**Правильный ответ: C** (нарушен критерий конкретности — что именно ученик сможет сделать после урока).

---

**Вопрос 3.** При AI-аудите урока учитель получил от ИИ рекомендацию. Какое действие нужно сделать обязательно?

- A) Сразу внести все предложенные правки
- B) Разделить рекомендацию на факты, выводы и предположения, проверить каждую часть
- C) Попросить ИИ переписать урок целиком
- D) Отправить рекомендацию завучу

**Правильный ответ: B** (проверка на безопасность — ИИ может ошибаться, его выводы нужно верифицировать).

---

**Вопрос 4.** Какая последовательность этапов проектирования урока с ИИ верна?

- A) Инструмент → задание → цель → критерии → формат
- B) Цель → формат → инструмент → задание → критерии
- C) Формат → цель → инструмент → критерии → задание
- D) Критерии → цель → инструмент → формат → задание

**Правильный ответ: B** (цель определяет всё остальное; инструмент подбирается под формат и цель, а не наоборот).

---

**Вопрос 5.** При проверке урока с позиции «Слабый ученик» (роль «Новичок») что именно проверяется?

- A) Соответствует ли урок ФГОС
- B) Какие шаги пропущены, где ученику потребуется дополнительная помощь
- C) Насколько урок интересен отличнику
- D) Корректность расчёта времени на каждом этапе

**Правильный ответ: B** (эта роль помогает найти скрытые разрывы в инструкциях и поддержке).

### 6.2. Защита практической работы (1 ч)

Слушатель представляет фрагмент урока / внеурочного занятия с ИИ, прошедший полный цикл AI-аудита.

#### Структура защиты (5–7 минут на человека)

1. **Тема и предмет** (30 сек) — какой предмет, класс, тема урока.
2. **Цель и задачи** (1 мин) — как сформулированы, почему выбрана именно такая формулировка.
3. **Выбор ИИ-инструмента** (1 мин) — какой инструмент, почему он подходит возрасту и задаче.
4. **Задание для учеников** (1 мин) — как звучит задание, какие промпты даны ученикам.
5. **Результаты AI-аудита** (1,5 мин) — ключевые проблемы, найденные на каждом шаге аудита.
6. **Доработки** (1 мин) — что изменено по результатам аудита, как это улучшило урок.

#### Критерии оценки

| Критерий | Макс. балл | Описание |
|---|---|---|
| 1. Цель и задачи сформулированы конкретно | 2 | Цель измерима, соответствует возрасту, включает ИИ-компонент |
| 2. Выбран подходящий ИИ-инструмент | 2 | Инструмент доступен, соответствует возрасту и типу задания |
| 3. Задание соответствует возрасту и предмету | 2 | Задание выполнимо, инструкция понятна, промпт корректен |
| 4. Урок прошёл AI-аудит (приложена таблица) | 3 | Заполнены все шаги аудита, найдены конкретные проблемы, предложены реалистичные правки |
| 5. Учтены правки по результатам аудита | 2 | Внесённые изменения отражены в финальной версии, результат аудита повлиял на проект |
| 6. Качество защиты | 2 | Чёткая структура, аргументация, ответы на вопросы |
| **Итого** | **13** | Для зачёта необходимо не менее 7 баллов |

**Порог успешной аттестации:** 7 баллов из 13.

#### Документы для защиты
- Описание фрагмента урока / внеурочного занятия (1–2 стр.)
- Заполненная таблица AI-аудита (все 5 шагов)
- Финальная версия фрагмента с учётом правок
