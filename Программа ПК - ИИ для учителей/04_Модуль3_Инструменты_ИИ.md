## Тема 3.1. Промпт-инжиниринг: базовые техники и приёмы (роль, контекст, формат, ограничения)

**Время:** лекция — 0,5 ч, практика — 1 ч, самост. работа — 0,5 ч

### Учебные вопросы

1. Понятие промпта и промпт-инжиниринга. Почему формулировка запроса определяет качество ответа.
2. Базовая структура промпта: роль, контекст, задача, формат, ограничения.
3. Типичные ошибки начинающего пользователя: размытые цели, отсутствие роли, смешение критериев.
4. Модель 5П как инструмент самопроверки промпта: Понятность, Полнота, Противоречия, Проблемы, Предложения.
5. Различие между запросом-генерацией («сделай») и запросом-аудитом («проверь»).

### Форма занятия

Лекция-демонстрация с разбором «плохих» и «хороших» промптов на примере учительских задач. Преподаватель показывает на экране, как меняется ответ ИИ при добавлении роли, контекста и ограничений.

### Описание практического задания

**Цель:** научиться формулировать промпты по схеме «роль — контекст — задача — формат — ограничение» и проверять их качество через AI-аудит.

**Задание 1. Конструирование промпта (20 мин)**

Слушатели получают «сырую» задачу от учителя и превращают её в полноценный промпт.

*Исходная задача:* «Составь задания по теме "Круговорот воды в природе" для 6 класса».

Слушатели дорабатывают запрос, последовательно добавляя:
- роль (учитель / методист / разработчик)
- контекст (какие темы уже пройдены, уровень класса)
- конкретную задачу (что именно нужно получить)
- формат вывода (таблица, список, текст)
- ограничения (объём, сложность, количество)

*Пример улучшенного промпта:*

> Ты — опытный учитель географии для 6 класса. Составь 5 разноуровневых заданий по теме «Круговорот воды в природе». Ученики уже знают понятия «испарение», «конденсация», «осадки». Задания распредели по уровням: 2 — базовых (узнавание/воспроизведение), 2 — повышенных (анализ/схема), 1 — высокий (объяснение причинно-следственных связей). Для каждого задания укажи планируемый ответ и время выполнения. Ответ дай в виде таблицы: номер задания — уровень — формулировка — ответ — время.

**Задание 2. AI-аудит собственного промпта (30 мин)**

Слушатели применяют AI-аудит к составленному промпту — проверяют его по модели 5П.

*Промпт для аудита промпта (на базе универсальной структуры из презентации Элоны, стр. 12):*

> Ты — эксперт по промпт-инжинирингу. Проведи аудит моего промпта ниже по критериям 5П: Понятность (что неясно), Полнота (чего не хватает), Противоречия (где логика ломается), Проблемы (что может пойти не так), Предложения (как исправить). Не переписывай промпт сразу. Сначала найди слабые места и объясни, почему это важно. Ответ дай в таблице: критерий / проблема / риск / рекомендация.
>
> Мой промпт: [слушатель вставляет свой промпт]

После получения таблицы слушатели вносят правки в свой промпт и фиксируют, что изменилось.

### Самостоятельная работа (0,5 ч)

1. Подобрать 3 учительские задачи из своей практики и составить к ним промпты по изученной структуре.
2. Провести AI-аудит каждого промпта по модели 5П.
3. Записать в дневник: что в моих типичных запросах к ИИ нуждается в улучшении.

### Ключевые понятия

Промпт, промпт-инжиниринг, роль, контекст, формат вывода, ограничения, модель 5П (Понятность, Полнота, Противоречия, Проблемы, Предложения), запрос-генерация, запрос-аудит.

## Тема 3.2. Генерация учебных материалов: тексты, изображения, презентации, тесты

**Время:** лекция — 0,5 ч, практика — 1 ч, самост. работа — 0,5 ч

### Учебные вопросы

1. Возможности ИИ для создания учебных текстов: объяснения, конспекты, памятки, адаптация сложного материала.
2. Генерация изображений и схем: когда уместно использовать, как формулировать запрос.
3. Создание презентаций с помощью ИИ: структура, наполнение, визуализация.
4. Генерация тестов и проверочных работ: типы заданий, уровни сложности, критерии оценки.
5. Ограничения ИИ-генерации: фактологические ошибки, устаревшие данные, «галлюцинации».

### Форма занятия

Лекция-обзор с демонстрацией сервисов (текстовые модели, генераторы изображений, сервисы презентаций). Практическая работа в парах.

### Описание практического задания

**Цель:** сгенерировать комплект учебных материалов по своей теме и провести AI-аудит полученного результата с помощью «совета экспертов» (5 ролей).

**Задание 1. Генерация материалов (30 мин)**

Слушатели выбирают одну тему из своего предмета и с помощью ИИ создают:

1. Текст объяснения нового материала (для учеников своего класса)
2. 3 тестовых задания разного уровня
3. План презентации (3–5 слайдов)

*Пример промпта для генерации:*

> Ты — учитель [предмет] для [класс]. Напиши объяснение темы «[тема]» для учеников [класс] класса. Используй простой язык, приведи 2 примера из жизни. В конце добавь шпаргалку: 3 главных факта, которые нужно запомнить. Объём — не более 1 страницы А4.

**Задание 2. AI-аудит сгенерированных материалов (20 мин)**

Слушатели проверяют полученные материалы с помощью промпта «совет экспертов» (из презентации Элоны, стр. 26), адаптированного под учительскую задачу:

> Проверь этот учебный материал с позиции пяти ролей: ученика (что непонятно / скучно / слишком сложно), учителя-методиста (соответствует ли программе, есть ли ошибки), родителя (безопасно ли, понятно ли, зачем это), коллеги-предметника (нет ли фактических ошибок, всё ли корректно), завуча (достигаются ли образовательные результаты). Для каждой роли найди 2–3 главных замечания. Не переписывай материал полностью. В конце выдели 3 правки, которые дадут наибольший эффект.
>
> Материал: [слушатель вставляет сгенерированный текст]

**Задание 3. Доработка (10 мин)**

По результатам аудита слушатели вносят 3 правки в исходный материал и фиксируют: что именно изменилось и почему.

### Самостоятельная работа (0,5 ч)

1. Сгенерировать по своей теме:
   - изображение или схему (можно использовать любой ИИ-генератор)
   - презентацию на 5–7 слайдов
2. Применить AI-аудит «совет экспертов» к презентации.
3. Записать в дневник: какие типы учебных материалов ИИ генерирует хорошо, а где нужна существенная доработка учителем.

### Ключевые понятия

Генерация, промпт-генерация, текстовые модели, визуальные модели, «галлюцинации» ИИ, совет экспертов, адаптация материала, уровни сложности, критериальная проверка.

## Тема 3.3. ИИ для проверки и обратной связи: анализ работ, рекомендации, критерии

**Время:** лекция — 0,5 ч, практика — 1 ч, самост. работа — 0,5 ч

### Учебные вопросы

1. Как ИИ может помочь в проверке ученических работ: возможности и границы.
2. Формулировка критериев оценки: от субъективных («хорошо») к измеримым («приведено 3 аргумента»).
3. ИИ для обратной связи: как формулировать развивающий комментарий.
4. Риски автоматической проверки: ложная уверенность, пропуск нестандартных решений.
5. Принцип «ИИ-ассистент, а не судья»: проверка с последующей верификацией учителем.

### Форма занятия

Лекция-разбор с примерами «хорошей» и «плохой» обратной связи. Практика — работа со своей проверочной работой.

### Описание практического задания

**Цель:** научиться использовать ИИ для проверки и обратной связи, а также проводить AI-аудит собственной проверочной работы на чёткость формулировок и критериев.

**Задание 1. Формулировка критериев (20 мин)**

Слушатели берут одно задание из своего предмета (например, сочинение, задача, лабораторная работа) и формулируют к нему критерии оценки. С помощью ИИ проверяют, насколько критерии измеримы.

*Промпт для проверки критериев:*

> Ты — методист по разработке критериального оценивания. Проверь формулировку задания и критерии оценки ниже. Найди: 1) какие критерии сформулированы неконкретно (субъективно), 2) какие аспекты ответа не покрыты критериями, 3) есть ли противоречия между критериями. Предложи, как переформулировать слабые критерии.
>
> Задание: [формулировка задания]
> Критерии: [список критериев]

**Задание 2. AI-аудит проверочной работы (30 мин)**

Слушатели загружают собственную проверочную работу (5–7 заданий) и проводят её аудит.

*Промпт для аудита проверочной работы (адаптация универсальной структуры, стр. 12):*

> Ты — эксперт по разработке учебных заданий. Проведи аудит проверочной работы ниже. Найди:
> 1. Какие формулировки заданий нечёткие или допускают двоякое толкование
> 2. Какие задания не проверяют то, что заявлено в цели
> 3. Где не хватает критериев оценки или инструкций для ученика
> 4. Есть ли задания с неоднозначным или устаревшим содержанием
> 5. Соответствует ли сложность заданий заявленному классу
>
> Не переписывай задания сразу. Сначала сделай диагностику. Ответ дай в таблице: номер задания / проблема / почему это риск / рекомендация.
>
> Проверочная работа: [текст работы]

После получения диагностики слушатели выбирают 2–3 задания, которые нужно доработать, и переформулируют их.

### Самостоятельная работа (0,5 ч)

1. Взять 3 работы учеников (реальные или смоделированные) и попросить ИИ:
   - проверить по критериям
   - написать развивающий комментарий (2 сильные стороны + 2 зоны роста)
2. Оценить качество обратной связи от ИИ: что можно использовать, а что нужно скорректировать.
3. Записать в дневник: в каких типах заданий ИИ помогает с проверкой, а где проверка учителем остаётся незаменимой.

### Ключевые понятия

Критериальное оценивание, обратная связь, развивающий комментарий, верификация, измеримые критерии, субъективные vs объективные критерии, ИИ-ассистент.

## Тема 3.4. AI-аудит как методический инструмент: проверка заданий, текстов, планов, КТП

**Время:** лекция — 0,5 ч, практика — 1 ч, самост. работа — 0,5 ч

### Учебные вопросы

1. AI-аудит как регулярная практика учителя: что можно проверять перед использованием на уроке.
2. «Совет экспертов»: методика проверки одного материала с 5 разных позиций.
3. Адаптация ролей под образовательный контекст (ученик, завуч, родитель, коллега, методист).
4. Алгоритм включения AI-аудита в подготовку к уроку: план → аудит → доработка.
5. Ограничения метода: ИИ не знает конкретного ученика, контекста класса, традиций школы.

### Форма занятия

Лекция-демонстрация полного цикла AI-аудита. Практика — полноценный разбор «Совет экспертов» (5 ролей из презентации).

### Описание практического задания

**Цель:** освоить методику «Совет экспертов» для проверки любых учебных материалов — от отдельного задания до календарно-тематического плана.

**Задание 1. Выбор материала для аудита (10 мин)**

Каждый слушатель выбирает один реальный материал из своей практики:
- фрагмент КТП на одну тему
- текст контрольной работы
- план урока
- текст памятки или инструкции для учеников
- описание проектного задания

**Задание 2. AI-аудит «Совет экспертов» (40 мин)**

Слушатели применяют к своему материалу адаптированную версию промпта из презентации (стр. 26):

> Проверь этот учебный материал с позиции пяти ролей:
>
> **1. Ученик** (вместо «клиента») — что непонятно, какие слова надо объяснить, где потеряется интерес, что кажется несправедливым или скучным.
>
> **2. Завуч / администратор** (вместо «руководителя») — соответствует ли материал рабочей программе, достижимы ли результаты, укладывается ли в отведённое время, есть ли измеримые критерии.
>
> **3. Слабый ученик / новичок** — какие шаги пропущены, где нужна подсказка, что вызовет ступор, какие задания он просто не сможет начать.
>
> **4. Коллега-скептик** — почему это не сработает в реальном классе, какие возражения от других учителей, где недооценка времени, что нужно доработать до проведения.
>
> **5. Методист / редактор** (вместо «редактора») — где вода, штампы, лишние слова, нелогичная структура, нарушение методических принципов (от простого к сложному, доступность, наглядность).
>
> Для каждой роли найди 3 главных замечания и предложи, что изменить. Не переписывай материал полностью. В конце выдели 5 правок, которые дадут наибольший эффект для реального урока.
>
> Материал: [слушатель вставляет свой материал]

После получения ответа слушатели:
1. Анализируют: какие роли дали наиболее полезные замечания
2. Выбирают 3–5 правок для внедрения
3. Вносят правки в исходный материал

**Задание 3. Рефлексия (10 мин)**

Обсуждение в парах: какие замечания ИИ были полезными, какие — спорными или неприменимыми. Почему важно сохранять критическое отношение к результатам аудита?

### Самостоятельная работа (0,5 ч)

1. Выбрать ещё 2 материала из своей практики (например, КТП на четверть и одно проектное задание).
2. Провести «Совет экспертов» для каждого.
3. Составить чек-лист из 5 вопросов, которые теперь будете задавать своему материалу перед уроком.
4. Записать в дневник: что изменилось в моём подходе к подготовке материалов после AI-аудита.

### Ключевые понятия

AI-аудит, совет экспертов, ролевая проверка, методическая экспертиза, чек-лист подготовки, итерация «создал — проверил — доработал», критическое отношение к результатам ИИ.

## Тема 3.5. Безопасность и этика: персональные данные, факты vs выводы vs предположения, дипфейки

**Время:** лекция — 0 ч (включена в 3.4), практика — включена в 3.4, самост. работа — включена в 3.4

*Примечание: тема 3.5 является сквозной и осваивается в рамках практических занятий 3.1–3.4 + выделенная практика на 0,5 ч. Для удобства планирования ниже даны материалы для самостоятельного блока.*

**Альтернативное распределение (рекомендуемое):**

| Темы | Лекции | Практика | Самост. работа |
|------|--------|----------|----------------|
| 3.1 | 0,5 | 1,0 | 0,5 |
| 3.2 | 0,5 | 1,0 | 0,5 |
| 3.3 | 0,5 | 1,0 | 0,5 |
| 3.4 | 0,5 | 0,5 | 0,5 |
| 3.5 | — | 0,5 | — |
| **Итого** | **2** | **4** | **2** |

### Учебные вопросы

1. Персональные данные учеников: что можно и нельзя загружать в ИИ-сервисы.
2. Анонимизация данных: как убрать имена, фамилии, личные характеристики.
3. Факты, выводы и предположения в ответах ИИ: почему важно различать.
4. Дипфейки и синтетический контент: как распознать и как объяснить ученикам.
5. Этические принципы использования ИИ в образовании: прозрачность, ответственность, равенство доступа.
6. Гигиена проверки: «ИИ ошибается и может звучать уверенно».

### Форма занятия

Практикум-обсуждение с разбором кейсов. Работа в группах.

### Описание практического задания

**Цель:** освоить приёмы безопасной работы с ИИ и научиться отличать факты от выводов и предположений в ответах ИИ.

**Задание 1. Границы дозволенного (10 мин)**

Слушателям выдаются 5 ситуаций. Нужно определить, в каких случаях загружать данные в ИИ можно, а в каких — нельзя и почему.

| Ситуация | Можно? |
|----------|--------|
| Загрузить список учеников класса с фамилиями и оценками | Нет |
| Загрузить условие задачи из учебника (без имён учеников) | Да |
| Загрузить сочинение ученика с его именем для проверки | Нет, нужно анонимизировать |
| Загрузить текст контрольной работы, разработанной учителем | Да |
| Попросить ИИ оценить психологическое состояние ученика по его тексту | Нет |

**Задание 2. Анонимизация (10 мин)**

Слушатели получают реальный фрагмент ученической работы и анонимизируют его: заменяют имена, удаляют личные детали, обобщают характеристики.

**Задание 3. Факты vs выводы vs предположения (20 мин)**

Слушатели проверяют полученный от ИИ ответ с помощью промпта из презентации (стр. 35):

> Проверь свой ответ. Раздели его на три блока: 1) факты из моего исходного материала, 2) твои выводы, 3) предположения, которые нужно проверить. Для каждого предположения напиши, какие данные нужны для подтверждения. Если где-то ты мог ошибиться или додумать, укажи это явно.

*Пример для отработки:* Слушатели сначала просят ИИ проверить ученическое эссе или решение задачи, а затем применяют этот промпт, чтобы отделить факты от домыслов в ответе самого ИИ.

*Полный цикл:*

> **Шаг 1.** Ты — учитель русского языка. Проверь сочинение ученика 7 класса на тему «Образ Печорина». Оцени по критериям: раскрытие темы, аргументация, грамотность. Дай развёрнутый комментарий.
>
> *[Слушатель получает ответ ИИ]*
>
> **Шаг 2.** *[вставляется промпт для проверки надёжности ответа ИИ]*

Результат: слушатель видит, какие утверждения ИИ — факты (взяты из сочинения), какие — выводы (логически следуют из текста), а какие — предположения (ИИ додумал сам).

**Задание 4. Этический кейс (10 мин)**

Групповое обсуждение: «Ученик использовал ИИ для выполнения домашнего задания. Как реагировать?»
- Варианты: запретить, разрешить с оговорками, перепроектировать задания.
- Слушатели формулируют позицию своей группы и аргументируют её.

### Самостоятельная работа (включена в 3.4)

Тема 3.5 не выделяет отдельную самостоятельную работу: навыки безопасности и этики отрабатываются сквозным образом в самостоятельных работах 3.1–3.4.

### Ключевые понятия

Персональные данные, анонимизация, факт, вывод, предположение, «галлюцинация» ИИ, дипфейк, синтетический контент, цифровая гигиена, этика ИИ в образовании, прозрачность использования.
