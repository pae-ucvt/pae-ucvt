# Памятка по безопасности при работе с ИИ

## 1. Что можно и нельзя загружать в ИИ

| Можно | Нельзя |
|---|---|
| Условия задач из учебника | ФИО учеников |
| Тексты заданий (без личных данных) | Оценки с привязкой к ученикам |
| Методические разработки | Номера телефонов, адреса |
| Анонимизированные работы | Коммерческие тайны школы |
| Открытые данные из интернета | Внутренние документы с пометкой «ДСП» |

## 2. Правило анонимизации

> **Замена:** Иванов → Ученик А, 7 «Б» → 7 класс, школа № 123 → школа в регионе
> **Удаление:** контакты, точные даты, внутренние шифры

## 3. Факты vs Выводы vs Предположения

| Тип | Пример | Статус |
|---|---|---|
| **Факт** | «В сочинении 3 орфографических ошибки» | Из данных |
| **Вывод** | «Ученик не знает правило безударных гласных» | Логически следует |
| **Предположение** | «Ученик невнимателен на уроках» | Нужно проверить |

**Промпт для проверки:**
> Проверь свой ответ. Раздели на три блока: 1) факты из исходных данных, 2) твои выводы, 3) предположения, которые нужно проверить. Если где-то ты мог ошибиться — укажи явно.
