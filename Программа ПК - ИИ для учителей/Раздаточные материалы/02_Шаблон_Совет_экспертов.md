# Шаблон «Совет экспертов»

Проверка одного материала с 5 разных позиций.

## 5 образовательных ролей

| Роль | Что проверяет | Ключевой вопрос |
|---|---|---|
| **Ученик** | Понятность, интерес, справедливость | «Что будет непонятно или скучно?» |
| **Завуч / администратор** | Соответствие программе, ресурсы, результаты | «Достижимы ли результаты за отведённое время?» |
| **Слабый ученик / новичок** | Пропущенные шаги, зоны «ступора» | «Где ему потребуется дополнительная помощь?» |
| **Коллега-скептик** | Реалистичность, риски, возражения | «Почему это может не сработать?» |
| **Методист / редактор** | Структура, логика, «вода», штампы | «Что можно улучшить в формулировках?» |

---

## Промпт

```
Проверь этот [материал] с позиции пяти ролей:

1. Ученик — что непонятно, какие слова надо объяснить, где потеряется интерес?
2. Завуч / администратор — соответствует ли рабочей программе, укладывается ли в отведённое время?
3. Слабый ученик / новичок — какие шаги пропущены, что вызовет ступор?
4. Коллега-скептик — почему это не сработает в реальном классе?
5. Методист / редактор — где вода, штампы, нелогичная структура?

Для каждой роли найди 2-3 главных замечания.
Не переписывай материал полностью.
В конце выдели 5 правок, которые дадут наибольший эффект.

Материал:
[вставить]
```

---

## Когда применять

- □ План урока
- □ Контрольная работа
- □ Текст памятки / инструкции
- □ Описание проекта
- □ Сценарий внеурочного занятия
- □ КТП на четверть / полугодие
