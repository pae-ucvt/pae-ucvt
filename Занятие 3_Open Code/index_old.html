Занятие 3. Open Code: от знакомства до анализа данных

Методическое пособие для преподавателя — 4 блока, 45 минут каждый

О занятии

Практическое занятие по работе с OpenCode Desktop. Студенты последовательно осваивают инструмент: от установки и первых запросов до анализа реальных файлов — папок, документов и таблиц Excel.

Длительность
180 мин (4 блока × 45 мин)
Уровень
с нуля
Формат
очный, с демонстрацией и самостоятельной работой

Что нужно подготовить

  1. Компьютер с Windows, интернет
  2. Папка для сортировки: 10–15 файлов разных типов (.docx, .jpg, .pdf, .txt) вперемешку
  3. 2–3 договора / инструкции в формате .docx или .txt
  4. Excel-таблица (до 100 строк)

Блок 1. Знакомство с OpenCode Desktop

Длительность
45–60 мин
Разделы
1.1–1.6

Конспект занятия

1.1. Скачиваем и устанавливаем OpenCode Desktop (10 мин)

Шаг 1. Открой браузер (Chrome, Edge или Яндекс).
Шаг 2. В адресную строку введи: opencode.ai/download
Шаг 3. На странице найди «OpenCode Desktop (Beta)» и кнопку «Windows (x64)» — нажми.
Шаг 4. Открой папку Загрузки → запусти установщик → Далее / Next → Готово.

1.2. Запускаем и знакомимся с интерфейсом (7 мин)

1. Открой OpenCode с рабочего стола или из меню Пуск.
2. Дождись загрузки. Если предложат войти (Sign in) — выбери «Пропустить».
3. Нажми «New Session» или «+» — откроется окно чата.
4. Оставь модель по умолчанию (Default / Auto).

Интерфейс: слева — файлы проекта; «+» — новый проект; «Открыть проект» — рабочая папка; справа — ход работы. Режимы: Build (основной) и Plan (планирование).

1.3. Первые запросы (13 мин)

  • «Привет! Как тебя зовут и что ты умеешь?»
  • «Покажи, как выглядит интерфейс: что за кнопки и панели вокруг?»
  • «Сколько сейчас времени и какой сегодня день недели?»
  • «Что ты можешь сделать? Назови 5 примеров»

1.4. Открываем рабочую папку (10 мин)

1. «В какой папке на компьютере я сейчас нахожусь?»
2. «Открой папку C:\Мои документы\Рабочая и покажи, что в ней есть»
3. «Сколько всего файлов и папок внутри?»

1.5. Система подтверждений и работа с сессиями (5 мин)

OpenCode никогда не выполняет действия без разрешения. Видишь запрос — читай, что будет сделано. Согласен — «Разрешить», сомневаешься — «Нет».

Одна задача — одна сессия. Закончил задачу → начни новую через + или /new.

1.6. AGENTS.md — правила для проекта (2 мин)

AGENTS.md — файл с инструкциями, как OpenCode должен работать с твоим проектом. Лежит в корне проекта. Можно создать командой /init. Глобальные правила — в C:\Users\user\.config\opencode\AGENTS.md.

Промпты для блока

Системный промпт — вводится в OpenCode для сравнения и дополнения конспекта Блока 1:

OpenCode Ты — методист, разрабатывающий учебные материалы. У тебя есть два файла: Блок_1_Знакомство_с_OpenCode.docx — готовый конспект занятия (4 раздела: установка, запуск, первые запросы, открытие папки) Из сессии Opencode_как эффективно работать со мной_и из других файлов.docx — расшифровка сессии с OpenCode, где обсуждаются интерфейс, режимы работы, подтверждения, сессии, AGENTS.md, формула запроса Задача: - Сравни содержимое обоих файлов - Найди в файле 2 информацию, относящуюся к Блоку 1 (знакомство, установка, интерфейс, первые шаги) - Добавь эту информацию в соответствующие разделы файла 1. Также добавь новые разделы, если найдёшь важные темы, которых нет в блоке 1 (например, «Система подтверждений», «Одна задача — одна сессия», «AGENTS.md») - Сохрани обновлённый файл Требования к стилю: - Простой язык, как для новичка - Сохрани нумерацию разделов (1.1, 1.2 и т.д.) - Добавленные фрагменты должны логически встраиваться в существующую структуру - Если информация из файла 2 относится к нескольким разделам — продублируй релевантные части
Примечание: Этот же промпт был выполнен в QWEN для сравнения результатов от разных моделей.

Блок 2. Порядок в папках

Длительность
45 мин
Разделы
2.1–2.5

Конспект занятия

2.1. Смотрим, что лежит в папках (10 мин)

«Покажи всю структуру папок и файлов — что у меня тут есть?»
«Покажи только файлы, сгруппируй по расширениям (.docx, .jpg, .pdf)»

2.2. Сортируем файлы по типам (15 мин)

«Отсортируй все файлы по типам: документы (.docx, .pdf, .txt) сложи в папку Документы, изображения (.jpg, .png) в папку Изображения, архивы (.zip, .rar) в папку Архивы, остальные — в Прочее»

OpenCode попросит разрешение — нажми «Разрешить» (это безопасно, файлы только перемещаются).

2.3. Проверяем результат (5 мин)

  • «Покажи новую структуру папок — что изменилось?»
  • «Сколько файлов в каждой папке?»
  • «Есть ли дубликаты одинаковых файлов?»

2.4. Бонус: аудит папки и дашборд (15 мин)

Шаг 1. «Проанализируй эту папку: сколько всего файлов, какие типы файлов, сколько места они занимают. Покажи топ-5 самых больших файлов»
Шаг 2. «Сделай из этого красивый HTML-дашборд с диаграммами по типам файлов и списком самых больших файлов. Тёмная тема. Сохрани как audit.html и открой в браузере»
Шаг 3. «Найди и удали все пустые папки»
Шаг 4 (бонус). «Сделай из анализа таблицу Excel с выводами и рекомендациями по организации»

2.5. Как правильно формулировать запросы (5 мин)

Формула хорошего запроса из 5 частей:

  • Цель — что нужно сделать
  • Контекст — подробности и примеры
  • Ограничения — чего не делать
  • Критерии качества — что считать хорошим результатом
  • Формат ответа — как вернуть результат

«Проанализируй папку Загрузки, покажи что занимает больше всего места, типы файлов и топ-10 самых больших. Сделай HTML-дашборд с диаграммами. Тёмная тема.»

Твоя задача — провести детальный анализ содержимого указанной папки C:\Users\user\Downloads\Блок 2 и предоставить структурированный, точный и легко читаемый отчет. Что нужно сделать в два этапа: Этап 1 — Анализ (только посмотреть, ничего не менять): 1. Просканируй всю папку Блок 2 и все её подпапки 2. Покажи мне структуру: какие папки есть, какие типы файлов, что повторяется 3. Найди дубликаты файлов (одинаковые имя + размер) 4. Предложи план реорганизации Этап 2 (только после моего подтверждения): 1. Удали дубликаты (оставить по одной копии) 2. Удали пустые папки 3. Создай папку КПК с предложенной структурой 4. Разложи файлы по папкам внутри КПК Важно: ничего не удаляй без моего согласия, каждый шаг показывай и спрашивай разрешение.

Блок 3. Анализ текстовых документов

Длительность
45 мин
Разделы
3.1–3.5

Конспект занятия

Три уровня задач с документами:

  • Уровень 1 — текстовый ответ (спрашиваешь — отвечает)
  • Уровень 2 — одно действие с файлом (прочитать, извлечь данные)
  • Уровень 3 — многоступенчатая задача (найти → прочитать → сравнить → сделать сводку)

3.1. Находим все документы (5 мин)

«Найди в этой папке все договоры — файлы, в названии которых есть слово договор или contract»
«Найди все файлы с расширением .docx в этой папке»

3.2. Читаем документ и извлекаем главное (15 мин)

«Прочитай файл Договор_поставки.docx и выдели: 1. Стороны договора 2. Сумму 3. Срок действия 4. Предмет договора 5. Особые условия (если есть)»

3.3. Сравниваем два документа (10 мин)

«Сравни файлы Договор_поставки.docx и Договор_услуг.docx. Покажи основные различия: суммы, сроки, условия»

3.4. Составляем сводку по всем документам (10 мин)

«Составь сводную таблицу по всем найденным документам: название файла, стороны, сумма, срок, статус (действует / истек). Если данных нет — напиши нет данных»
Бонус: «Найди во всех документах упоминания НДС, пени, штрафов — выпиши отдельно»

3.5. Как улучшить запросы для анализа документов (5 мин)

Пример хорошего запроса для этого блока:

«Прочитай все договоры в этой папке. Для каждого договора выдели: стороны, сумму, срок, предмет договора. Если данных нет — пиши нет данных. Результат верни в виде таблицы в чате.»

Блок 4. Анализ таблиц Excel

Длительность
45 мин
Разделы
4.1–4.5

Конспект занятия

4.1. Превращаем Excel в CSV (10 мин)

OpenCode не читает .xlsx напрямую. Конвертируем: Файл → Сохранить как → тип «CSV (разделители — запятые)».

4.2. Читаем CSV — знакомимся с данными (10 мин)

  • «Прочитай файл tablica.csv и покажи первые 10 строк»
  • «Сколько всего строк и столбцов в таблице?»
  • «Как называются столбцы?»
  • «Есть ли пустые ячейки? В каких столбцах?»

4.3. Анализируем данные (15 мин)

Итоги: «Посчитай общую сумму по столбцу Сумма»

Фильтрация: «Покажи только те строки, где сумма больше 10 000»

Аномалии: «Найди дубликаты по столбцу Номер заказа»

Группировка: «Сгруппируй данные по столбцу Категория и покажи сумму по каждой категории»

4.4. Сложный пример: объединяем две таблицы (5 мин)

«Возьми из обоих CSV-файлов столбец Расходы и сделай новую таблицу с единственным листом, где будут расходы за все 24 месяца. После этого сделай Markdown-файл, в который добавь анализ моих расходов за два года и тренды, которые ты определишь»

4.5. Что еще можно автоматизировать (5 мин)

Идеи для самостоятельной работы:

  • «Создай отчет по таблице и сохрани его в новый файл»
  • «Объедини две таблицы в одну»
  • «Сконвертируй таблицу из CSV в Excel с оформлением»
