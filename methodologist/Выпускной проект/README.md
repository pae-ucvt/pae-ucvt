# @methodologist — Суб-агент для разработки ДПП ПК

AI-ассистент (суб-агент Open Code) для создания программ повышения квалификации педагогов, планов занятий и тестов.

## Возможности

| Команда | Результат |
|---------|-----------|
| `@methodologist создай программу по теме "..." на 36 часов` | ДПП ПК из 7 разделов |
| `@methodologist составь план занятия по теме "..."` | План занятия с хронометражем |
| `@methodologist сделай тест по теме "..."` | Тест из 10 вопросов + ключ |

## Быстрый старт

1. Открой папку `methodologist/` в Open Code
2. Набери команду, например:
   ```
   @methodologist создай программу курса по теме "Нейросети в работе преподавателя" на 36 часов, категория — преподаватели СПО
   ```
3. После генерации `.md` конвертируй в Word:
   ```
   python scripts/convert_to_docx.py "Нейросети в работе преподавателя.md"
   ```

## Технологии

- Open Code — платформа AI-агентов
- Модель: big-pickle (temperature 0.2)
- Формат вывода: Markdown

## Целевая аудитория

Программы рассчитаны на педагогов:
- Школы и СПО
- Дошкольное образование
- Дополнительное образование
- Методисты и руководители

Объём программ: 36 часов (по умолчанию).
