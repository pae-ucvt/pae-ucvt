# Описание проекта

---

## Название

**«Конструктор учебных программ»**

---

## Проблема

Составление дополнительных профессиональных программ (ДПП) повышения квалификации — рутинная задача для методистов. На одну программу уходит от нескольких часов до нескольких дней: нужно выдержать структуру из 7 разделов, распределить часы, привязать к профстандарту, оформить по ГОСТу. При этом формат повторяется: пояснительная записка, учебный план, календарный график, содержание, критерии оценивания, литература.

Проблема усугубляется, когда нужно:
- адаптировать программу под разные объёмы (36 ч, 72 ч)
- перевести из .md в .docx с правильным оформлением
- обеспечить единый формат для всех программ организации

Сейчас это делается вручную или на разных инструментах. «Конструктор» объединяет процесс в одну цепочку.

---

## Пользователь

**Методисты педагогических организаций:**
- центры повышения квалификации

- отделы методического обеспечения
- единичные преподаватели, которые сами готовят программы

## Основная функция

### Что подаётся на вход

| Параметр | Пример |
|----------|--------|
| Название программы | «Нейросети в работе преподавателя» |
| Цель и задачи | Формирование компетенций в области ИИ |
| Категория слушателей | Преподаватели СПО |
| Объём часов | 36 или 72 |
| Количество занятий | 9 (при 36 ч) или 18 (при 72 ч) |
| Содержание занятий | Темы, описания, контрольные вопросы |
| Профстандарт | Трудовые функции (при наличии) |
| Город / год | Санкт-Петербург, 2026 |

### Что получается на выходе

| Формат | Описание |
|--------|----------|
| `.docx` | Готовый Word-документ программы с оформлением: титул, таблицы, заголовки, списки |
| `.md` | Исходный Markdown-файл для редактирования |
| `.json` | Структурированные данные программы для повторного использования |

### Инструменты

- **scripts/build_program.py** — скрипт параметрической генерации .docx из JSON
- **scripts/convert_to_docx.py** — конвертер .md → .docx
- **templates/constructor_template.md** — шаблон программы с placeholder'ами и инструкцией
- **Выпускной проект/Нейросети в работе преподавателя/neural_networks.json** — пример заполненного JSON-файла

## Формат результата

Пользователь получает:

1. **Готовый Word-документ** — программа повышения квалификации, оформленная по стандарту: титульный лист, учебный план, пояснительная записка, содержание занятий, критерии оценивания, список литературы
2. **Markdown-файл** — для быстрого редактирования и хранения
3. **JSON-файл** — для пересоздания программы или адаптации под другой объём

Для запуска новой программы достаточно:
- скопировать JSON-шаблон
- заменить данные
- запустить одну команду

## Как запустить

### Быстрый старт

1. Установить зависимости:
   ```bash
   pip install python-docx openpyxl
   ```

2. Скопировать JSON-шаблон и заполнить своими данными:
   ```bash
   cp "Выпускной проект/Нейросети в работе преподавателя/neural_networks.json" my_program.json
   ```

3. Сгенерировать .docx:
   ```bash
   python scripts/build_program.py my_program.json
   ```

4. Готовый документ появится рядом с JSON-файлом.

### Пример запуска

```bash
python scripts/build_program.py "Выпускной проект/Нейросети в работе преподавателя/neural_networks.json"
# Результат: Нейросети в работе преподавателя.docx
```

## Демонстрируемость

Проект стабильно работает и каждый шаг можно продемонстрировать:

1. **Показ JSON-файла** — наглядная структура данных, которую легко заполнить
2. **Запуск скрипта** — одна команда `python scripts/build_program.py ...`
3. **Готовый .docx** — открывается в Word, содержит все 7 разделов программы
4. **Markdown-файл** — доступен для просмотра в любом редакторе

Все шаги работают локально, без внешних сервисов и API.
